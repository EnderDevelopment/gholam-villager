# Smart Villager Mod

This Minecraft mod introduces a smart villager for Minecraft version 1.20.1 using Forge. The villager is designed to speak Persian, loves emeralds, and works as a YouTuber. It features custom behavior, a unique appearance, and the ability to interact with players in a friendly and engaging manner.

## Install

1. Download the mod file (smartvillager-1.0.0.jar) from the releases section of the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and select the Forge profile for version 1.20.1.

## Use

1. Spawn the smart villager in the game world.
2. Interact with the villager to engage in conversations in Persian.
3. Observe the villager's unique behavior, including its love for emeralds and its YouTuber profession.
4. Enjoy the custom appearance and sound effects of the smart villager.
